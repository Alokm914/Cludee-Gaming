CLUDEE GAMING — STARTER WEBSITE
================================

FILES
-----
index.html  = page content and structure
style.css   = layout, colors, typography and responsive design
script.js   = mobile navigation and current year

HOW TO OPEN IN VS CODE
----------------------
1. Extract the ZIP file to a folder you can find easily.
2. Open VS Code.
3. Select File > Open Folder.
4. Choose the extracted "cludee_gaming_starter" folder.
5. Open index.html.
6. If you have the Live Server extension:
   - Right-click index.html
   - Choose "Open with Live Server"
   Otherwise, open index.html directly in your browser.

CUSTOMIZE FIRST
---------------
1. Confirm the brand name and visual identity with the founder.
2. Replace the CG text mark with an approved logo if one is supplied.
3. Confirm the channel statistics before treating them as current.
4. Add real player names/photos only after the players and founder approve.
5. Add real video embeds only after selecting the videos to feature.
6. Check every social link before publishing.

PUBLISHING
----------
This is a static website and can be hosted on GitHub Pages.
Do not publish it as the official organization website until the founder
has approved the design, content, links and use of the brand.

PRIVACY AND SECURITY
--------------------
- This demo has no database and collects no visitor information.
- Do not put player phone numbers, personal emails, passwords or private
  account details in the website.
- Never place API keys, passwords or private tokens in HTML, CSS or JS.
- Use only approved public links and media.

NOTES
-----
- The channel statistics shown are based on the screenshots supplied
  for this project and may become outdated.
- The roster is intentionally a "coming soon" placeholder. No player
  identities or achievements have been invented.
- Google Fonts requires an internet connection. The page has fallback
  system fonts if the font service is unavailable.
